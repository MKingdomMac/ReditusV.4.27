TileMapEditor UE4.27 v1.2.60 - Visible Slant Diagnostics
=======================================================

This is the v1.2.59 diagnostic build with one UI correction:

- "Debug Slant Supports" is now an ordinary visible property directly below
  "Use Continuous Terrain Prototype" in the terrain actor's Continuous Terrain
  Details category.
- It no longer depends on Unreal's advanced-property display.
- It remains false by default.

No terrain geometry, masks, materials, collision, or diagnostic calculations
were changed from v1.2.59.
